01 / Experimental design

Three experiments.
One held-out test set.

Each experiment evaluates the same five classifiers. SMOTE is applied to the training split only; the held-out test split is never resampled.

01 · Baseline

Original training distribution

Train and evaluate with all 512 input features, without oversampling.

02 · SMOTE

Resampled training data

Apply SMOTE to the training split, then evaluate with all 512 input features.

03 · Bonus experiment · separate pipeline

SMOTE + feature selection

This experiment adds scaling and chi-squared feature selection after resampling. It is distinct from baseline and standard SMOTE.

SMOTE→MinMaxScaler→SelectKBest (chi²)→256 Features→Model Evaluation

Split: stratified 80/20 · random_state=42 · Models: Random Forest, SVC (RBF), Decision Tree, AdaBoost, MLP.

04 / From the recorded results

Key findings

Observations below refer only to the supplied result files and evaluated models.

54.56%

Random Forest recorded the highest macro F1 among the five models in the standard SMOTE experiment.

+7.94 pts

Random Forest macro F1 increased from 46.63% baseline to 54.56% after SMOTE; accuracy moved from 57.34% to 57.00%.

52.24%

Random Forest had the highest macro F1 in the feature-selection experiment; the experiment evaluated 256 selected features.

Changes are descriptive comparisons of the recorded experiment results, not evidence of performance on other datasets or real-world files.

05 / Context

Cybersecurity relevance

File categorization and automated file analysis can support broader security workflows by helping organize or route files for additional analysis. This project studies classification from a precomputed feature table only.

It does not assess whether a file is malicious, detect threats, or replace security controls. The feature-generation process is not established by the supplied scripts.

06 / Research boundaries

Limitations & future work

Current limitations

  • No verified raw-file-to-feature extraction pipeline is included.
  • The project cannot classify arbitrary uploaded files.
  • The 512 feature columns’ generation method is not established by supplied code; the CSV filename alone does not verify SIFT descriptors.
  • No fitted models or preprocessing artifacts are saved for inference.
  • Dataset source and redistribution license are not documented in the supplied files.

Future work

  • Implement and verify the original feature-extraction process.
  • Save fitted models, scaler, and feature selector.
  • Build a prediction-only pipeline for validated feature vectors.
  • Evaluate security-specific datasets if the research scope expands.

These are proposed improvements, not current features.
